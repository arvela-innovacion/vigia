# Paquete de traspaso VIGIA → ChatGPT Work

Este ZIP contiene **solo documentación y un script de inventario**. No contiene el código del repositorio, modelos, vídeos, bases de datos ni secretos.

## Uso
1. Verifica que el repositorio privado `arvela-innovacion/vigia` contiene el código y el README principal.
2. Abre un chat nuevo de ChatGPT Work y conecta el repositorio o adjunta el ZIP del código.
3. Adjunta este paquete de traspaso o copia su contenido a la raíz del repositorio (por ejemplo bajo `docs/`).
4. Pega el texto de `MENSAJE_INICIAL_WORK.md` como primer mensaje.
5. Pide primero auditoría sin cambios y valida los hallazgos.
6. Si quieres fijar dependencias, ejecuta `inventariar_entornos.sh` en la Raspberry, revisa sus resultados y entrégalos a Work.

## Alcance y fiabilidad
Reconstruido a partir del contexto disponible de conversaciones anteriores. No equivale a una inspección del código real ni a un archivo exhaustivo de todas las conversaciones. Los detalles históricos están marcados como tales y deben comprobarse en el repositorio.
